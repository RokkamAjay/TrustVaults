My project is called **TrustVault**, a secure document management web application developed using Python and Flask.

The main purpose of this project is to store documents and control who can access them. It supports three roles: Admin, Owner, and Viewer. Each role has different permissions.

Users can log in, and authorized users can upload, access, or download documents. The application also includes audit logging to track important activities. I have added a user-friendly interface with light and dark themes and motivational quotes.

Through this project, I am learning about Flask, database management, authentication, role-based access control, and web application development.
